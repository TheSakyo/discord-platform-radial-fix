# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-18

### Added
- Initial public release.
- PlatformIndicators layout fixes (member list, user profiles, messages).
- Hidden duplicate mobile phone icon drawn by RadialStatus.
- Custom typing indicator: default Discord pill with three animated dots, replacing RadialStatus' misplaced gray circle.
- `--vc-typing-bg`, `--vc-typing-width` and `--vc-typing-height` variables to customize the typing pill.
- English and French README.
